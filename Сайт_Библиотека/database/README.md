# База данных «Полки» (Supabase)

## Как подключить

1. Создайте проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor** и по очереди выполните файлы целиком, каждый один раз:
   - `01_schema.sql` — таблицы, связи, триггеры и функции;
   - `02_security.sql` — права доступа (RLS);
   - `03_seed.sql` — 30 книг, 251 глава, подборки, магазины и ссылки.
3. Откройте **Project Settings → API**. Скопируйте **Project URL** и **anon public key** в `js/config.js`:
   ```js
   const SUPABASE = { url: 'https://xxxx.supabase.co', anonKey: 'eyJ…' };
   ```
4. Откройте **Authentication → URL Configuration**. В **Site URL** укажите адрес сайта, например `https://логин.github.io/polka/`. По этому адресу ведут ссылки из писем: подтверждение почты и сброс пароля. Если сайт открыт двойным щелчком по файлу, вход и регистрация работают, но ссылки из писем открыться не смогут.

Проверка: `04_queries.sql` — запросы для запуска по одному, как в StudentHub.

Пока `url` и `anonKey` пустые, сайт работает на `js/books.js`, как раньше: без аккаунтов и отзывов, избранное хранится в браузере.

## Схема

```
genres ─┐                         stores ─────────────┐
        │ 1:N                       │ 1:N             │
        ▼                           ▼                 │
      books ◄── chapters (N:1)    book_links ──► books│
        ▲  ▲                                          │
        │  └── book_collections ──► collections       │
        │       (N:M, position — порядок на главной)  │
        │                                             │
        │                books.free_source ───────────┘
        │
        ├── user_books ──► auth.users ◄── profiles (1:1)
        ├── reviews    ──► auth.users
        └── book_views ──► auth.users (может быть пустым)
```

| Таблица | Что хранит |
|---|---|
| `genres` | жанры: плитки на главной и фильтр |
| `books` | книги. `source = 'polka'` — свой каталог; `'gb'` / `'ol'` — книги из Google Books / Open Library, которые кто-то положил на полку или оценил |
| `chapters` | содержание по главам, `unique (book_id, position)` |
| `collections`, `book_collections` | подборки и какие книги в них входят (многие-ко-многим) |
| `stores`, `book_links` | магазины с шаблоном поиска `{q}` и кнопки «Где взять» у каждой книги |
| `profiles` | имя пользователя у отзывов; создаётся само при регистрации |
| `user_books` | полка: избранное и статус `want` / `reading` / `read` |
| `reviews` | оценка 1–5 и текст; один отзыв от человека на книгу |
| `book_views` | просмотры страниц для статистики |

Функции:
- `popular_books(дней, сколько)` — самые открываемые книги. На главной они поднимаются в начало ряда «Популярное».
- `ensure_external_book(...)` — сохраняет книгу из API перед тем, как на неё сошлётся полка или отзыв.

Представление `book_ratings` — средняя оценка читателей по каждой книге.

## Безопасность

anon-ключ виден в коде страницы, так задумано в Supabase. Данные защищает RLS из `02_security.sql`:

- каталог все только читают, менять его может владелец проекта в Table Editor;
- полку каждый видит и меняет только свою;
- отзывы читают все, а меняет и удаляет только автор;
- просмотры можно только добавлять, читать их нельзя;
- проверки в таблицах не дают поставить оценку вне 1–5 или написать второй отзыв на ту же книгу.

## Как добавить книгу

**Table Editor → books → Insert row.** Затем добавьте главы в `chapters`, подборки в `book_collections` и кнопки в `book_links`. Сайт обновит каталог в течение 10 минут (столько живёт кэш в браузере).

Если удобнее править `js/books.js`, пересоберите начальные данные командой `node database/tools/build_seed.js`. Команда перезаписывает `03_seed.sql`. Он рассчитан на пустую базу: на уже заполненной повторный запуск остановится на дублях.
